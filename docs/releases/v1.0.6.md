# 🚀 Release Notes (v1.0.5 -> Latest)

### 🌟 新特性与交互升级 (Highlights)

- **🎨 全新独立设置中心（800 × 500）**
  - 重构为三标签页架构：**外观与显示**、**中转站管理**、**系统设置**。
  - 外观配置采用双列自适应网格，操作更加清晰宽敞。
- **📊 托盘悬浮即时概览（Tray Hover Preview）**
  - 鼠标悬停系统托盘图标即可唤出透明磨砂概览卡片。
  - 实时展示今日消耗明细、周期额度进度、窗口重置时间与当前激活数据源。
- **💰 余额按量计费模式（Pay-as-you-go）**
  - 自动识别无周期限额的数据源，展示钱包余额、今日消耗、累计消耗和计费模式。
  - 余额不足、余额耗尽或数据源失效时提供独立的视觉状态提示。
- **📌 贴边微型进度条（Dock Bar）**
  - 悬浮球贴靠屏幕边缘时自动切换为极窄竖向流光进度条形态，最小化视觉干扰。
  - 双击微型进度条即可快速呼出完整信息。
- **⚡ 统一右键快捷菜单（Quick Menu）**
  - 托盘与悬浮球共享统一样式的暗色玻璃质感快捷菜单。
  - 支持快捷切换数据源、一键切换多种主题、强制刷新用量。
- **🌐 增强型中转站与数据源配置**
  - 新增多种中转站预设与自定义 Headers 灵活配置。
  - 改善连接测试体验，支持快速探测延迟与接口健康状态。
