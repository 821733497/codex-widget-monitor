# 🚀 Release Notes (v1.0.6 -> v1.0.7)

### 🌟 悬浮球交互与视觉升级

- **🌊 拖拽流体动效**
  - 悬浮球拖动时加入基于速度与惯性的液体晃动、波浪扰动和回弹效果。
  - 多种主题共享统一的动效基座，保持不同主题的颜色和材质表现。
- **🖱️ 单击呼出托盘概览**
  - 单击悬浮球即可快速打开或收起托盘用量概览卡片。
  - 保留双击回到完整面板和右键快捷菜单等原有交互。
- **📍 托盘预览定位优化**
  - 记忆最近的托盘图标位置，点击悬浮球打开预览时自动使用合理的默认定位。
- **🔄 开发模式更新保护**
  - 开发环境检测到新版本时只展示更新状态，不会自动下载或安装，避免本地调试被更新流程打断。

### ✅ 发布前验证

- 前端 lint、测试和生产构建通过。
- Rust 格式、Clippy 和单元测试通过。
- npm 依赖安全审计通过。
